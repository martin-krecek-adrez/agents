# Thread Handoff Template

Use [adrez-thread-handoff](../skills/adrez-thread-handoff/SKILL.md) to prepare or
receive a focused continuation. Its bundled
[handoff prompt](../skills/adrez-thread-handoff/references/handoff-template.md)
is the maintained template.

Ask "Připrav předání této práce do nového chatu" for a filled prompt.
Ask "Založ nový chat a předej mu tuto práci" to also create the destination.
Save a handoff to a task note only when requested.
